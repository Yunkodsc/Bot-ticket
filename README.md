# Bot-ticket
le bot marche avec nodejs avec la version de node v26.9.0 et le npm en 11.19.1 et le dotenv en 16.6.1

Mettez toutes les informations qu'a besoins le bot dans le .env
N'oubliez pas d'activer les intents du bot dans le discord dev portal 
Ensuite, faites npm i discord.js et apres npm i discord.js dotenv (n'oublier pas de supprimer le fichier package-lock.json et le package.json.
Ensuite configuré les owners dans ney-owners.json
Vous n'avez qu'a lancer le bot en faisant node deploy-commands.js et apres npm start
